# BeautySalon — конфигурация 1С

Проект конфигурации для салона красоты (BeautySalon).

## Цель проекта

Автоматизация учёта в салоне красоты: склад, цены, бухгалтерский учёт, отчётность и запись клиентов. Конфигурация рассчитана на малый бизнес с возможностью масштабирования и адаптации под учётную политику компании.

## Реализованный функционал

- Внедрение БСП в "пустую" конфигурацию (Базовая функц-ть, Подключаемые команды, Обновление версии ИБ, Конструктор формул, Организации, Пользователи, Печать, Дополнительные отчеты и обработки).
- Складской учёт и контроль остатков: формирование актуальных остатков по номенклатуре, контроль отрицательных остатков при проведении документов.
- Регистр сведений «Цены номенклатуры» — для хранения и получения актуальных цен в разрезе номенклатуры и вида цены. Загрузка непосредственно в регистр из файла Excel
- Бухгалтерский учёт: реализован бухгалтерский регистр с привязкой к счетам бухгалтерского учёта, план счетов (хозрасчётный), план видов характеристик и виды субконто.
- Отчёты: анализ движения средств, контроль остатков, анализ продаж (услуг) в разрезе мастеров и номенклатуры, оборотно-сальдовая ведомость (ОСВ).
- Печатная форма: «Товарная накладная» — сформирована и подключена в конфигурации.
- Мобильная конфигурация (: реализована запись клиента в салон красоты (интеграция и логика записи).

## Технологии и особенности хранения кода

- Платформа: 1С:Предприятие 8.3
- Выгрузка в XML.
- Система контроля версий: Git
- Настроен .gitignore: исключены файлы базы (1Cv8.1CD), кэш и логи — чтобы в репозитории был только код конфигурации.

## Инженерные особенности и ценность

- Реализована структура учёта (субконто, план счетов, характеристики), позволяющая гибко настраивать аналитику без изменения кода.
- Пример ценности (X‑Y‑Z): автоматизация контроля остатков устранила ручные проверки и снизила риск ошибок при списании, что ускоряет закрытие смены и повышает точность управленческих данных.
- Аналогичные принципы учёта применены в проекте «Груминг»: управленческий учёт без двойной записи и регламентированной отчётности.
